# web-tuner-metronome

Next.js + Reactで構築されたWebベースのチューナー・メトロノームアプリケーション

## 機能

- **メトロノーム**: テンポ調整可能な視覚的・音響的メトロノーム
- **チューナー**: リアルタイム音程検出機能付きチューナー

## 開発

```bash
npm install
npm run dev
```

## ビルド・デプロイ

```bash
npm run build
npm run export
```
